# Matriks approval [RESMI, dari Struktur 5 AI Agent §05]

| Hasil pekerjaan | Pihak yang menyetujui | Peran di sistem AI Office |
|---|---|---|
| Tema dan angle konten | Reviewer / Mbak Nia | Approver (konten) |
| Carousel dan image | Reviewer / Mbak Nia | Approver (konten) |
| Video internal dan eksternal | Reviewer / Mbak Nia | Approver (konten) |
| Caption dan publikasi | Reviewer sesuai SOP | Approver (publikasi) |
| Ads creative dan copy | Marketing / atasan | Approver (iklan) |
| Budget dan running Ads | Pemegang otorisasi budget | **Budget Approver** |
| Testimoni dan izin publikasi | Pemilik cerita dan pihak berwenang | Dicatat sebagai *consent record*, diverifikasi Approver |
| Tema event, creative event, dokumen (TOR/SKB), landing page, payment flow | Reviewer event (sesuai workflow Event Specialist) | Approver (event) |

## Aturan sistem [DRAFT]
- Setiap item di kotak Approval menampilkan: brand, agent, jenis pekerjaan, sumber/izin (jika ada), dan biaya AI.
- Item yang ditolak wajib disertai catatan; catatan dikirim kembali ke agent sebagai revisi.
- Target waktu approval: < 24 jam untuk konten organik.
- Approval tercatat di audit log: siapa, kapan, keputusan, catatan.
