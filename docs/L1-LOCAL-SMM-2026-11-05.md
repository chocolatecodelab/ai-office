# L1 SMM — pengujian lokal

Keputusan pengguna: akun Meta/Drive dan Supervisor belum tersedia; siapkan dan uji lokal. Semua endpoint sosial di bawah mock/local-preview, bukan koneksi akun nyata. Tidak ada posting, balasan, moderasi, atau pengesahan FAQ eksternal.

## Cara mencoba dari chat

1. Buka Social Media Manager pada brand yang diinginkan.
2. Lampirkan docs/fixtures/l1-smm-comments-20.json melalui tombol lampiran.
3. Pilih skill Klasifikasi komentar, lalu kirim permintaan untuk meninjau kategori dan prioritas.
4. Tool deterministik membaca JSON sebelum jawaban model dan dicatat sebagai comment-classification pada Konteks yang digunakan. Penjelasan chat tetap menggunakan runtime/model normal dan dapat memakai kuota.
5. Tinjau hasil dengan docs/fixtures/l1-smm-review-20.csv; kolom reviewer awal NOT_REVIEWED.

Format: objek comments berisi1–20 item unik {id,text}, maksimal2000 karakter per komentar. Satu batch dari seluruh lampiran JSON maksimal20 komentar. File invalid/duplikasi ditolak, tanpa klaim berhasil. Skill hanya tersedia bagi SMM.

## Endpoint pemeriksaan lokal

- GET /api/office/brands/:brand/social/mock/comments: tiga komentar sintetis dengan ID brand.
- GET /api/office/brands/:brand/social/mock/faq: tiga FAQ draft operasional, approval not-approved dan autoReply false.
- POST /api/office/brands/:brand/social/mock/classify: payload {comments:[{id,text}]} menghasilkan kategori, FAQ cocok dan saran review. Tidak memanggil model atau layanan sosial.
- Endpoint social-schedule sebelumnya tetap rencana lokal yang membutuhkan caption SMM approved, bukan posting.

## Batasan dan penerimaan

Kategori kata kunci: sensitive, complaint, spam, lead, faq, praise, manual. Prioritas sensitive/complaint mendahului FAQ. Semua hasil reviewRequired true, autoReply false, moderationAction none. Nama/ironi/konteks dapat membuat klasifikasi keliru. Komentar diperlakukan sebagai data, bukan perintah tool. Deteksi sensitive terbatas, bukan perlindungan privasi lengkap. FAQ hanya arahan verifikasi internal; tidak mengarang harga/jadwal/program dan tidak boleh dipakai sebagai template balasan publik approved.

20 contoh sintetis dipakai untuk regresi teknik. Kategori harapan ditulis pengembang; belum validasi Supervisor, bukan20 tugas produksi disetujui tanpa revisi dan bukan kelulusan L1-12.

L1-07 kini memiliki pembacaan fixture dan klasifikasi lokal, tetapi provider read_comments serta worker publishing belum tersedia. L1-11 memiliki FAQ/20 fixture lokal; KB resmi tetap menunggu sumber dan Supervisor. L1-09 tetap belum diuji akun nyata.
