# EditorialStudy R3

Source for the experimental OTCA Nina R3 storyboard. Native installed entry: video-system/remotion/src/OfficeEditorialR3.tsx. Uses the existing native font-token loader and Remotion dependencies. Project props and word timings: video-system/proyek/2026-11_otca-nina-office-r3/storyboard-props-r3.json. Composition: EditorialStudyR3, 1080x1920, 30 fps, 1547 frames. Runtime timings and scenes come from props; stills and future production share the same React component. The module is a draft visual grammar for study funding, not a universal template for all brands.

No MP4 export or native approval has been performed. Human review is required. Brand typography, safe areas, timing, transcription accuracy, motion continuity, audio mix and final export must be checked before approval and production. Full automated brief-to-composition generation is not implemented by this example.

R4 revises the portrait treatment: footage extends behind the composition; a continuous dark gradient supplies contrast, replacing the hard upper-stage/lower-talent boundary. Subtitle backing is transparent on portrait scenes. The earlier full-motion cutaways remain for variation. Native entry and props follow the R4 project names. R3 remains available and its approval does not carry over.

R4 visual refinement uses a softly blurred full-frame footage underlay and a feathered portrait layer; this removes the uncovered top strip caused by the portrait offset. Both layers use the same source/timestamp. Final motion and encode QA are still pending.
